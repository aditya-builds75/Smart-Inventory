# Smart Inventory Dashboard (Power BI)

## Overview

Smart Inventory Dashboard is a Power BI project designed to help businesses monitor and manage inventory data efficiently. The dashboard provides insights into stock availability, inventory movement, product performance, and overall business operations through interactive visualizations and reports.

This project is useful for:

* Inventory tracking
* Stock management
* Sales and product analysis
* Business reporting
* Data-driven decision making

## How to Use

1. Download the `.pbit` file.
2. Open the file in Microsoft Power BI Desktop.
3. Connect your dataset if required.
4. Refresh the data.
5. Explore the dashboard and reports.
